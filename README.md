# 抓抓挑选器 🎧

> Otome Audio Picker · 乙女向音声的私人购买决策工具（V1.0）

单页 HTML、无需安装依赖，支持手机和电脑。帮助听众按自己的偏好筛选折扣作品，再根据预算进行二次取舍。

## 直接使用

- 下载 `index.html`，使用浏览器打开。
- 或者在仓库 Settings → Pages 中，选择 **Deploy from a branch**、`main` / `/(root)`，等待 GitHub Pages 发布后使用网页地址。
- 所有作品信息与评分会自动保存在**当前浏览器 localStorage**。换设备/清除浏览器数据前，进入「设置」导出 JSON；在另一台设备使用「导入备份」。

## RJ 号自动导入（新增）

在「第一印象」步骤输入 `RJ123456`（也支持 `BJ...`），点击「自动获取作品信息」。工具会调用与乙抓记录站共用的 Cloudflare Worker：

`https://dlsite-rj-import.shuiyingsheng.workers.dev/?workno=RJ123456`

- 尽可能导入**作品名称、CV、社团、封面、标签、官方简介、时长**；是否实际返回某个字段取决于 DLsite 接口。官方简介同时显示在「详情排雷」步骤。
- **DLsite 日元原价会按最新可获取的 JPY/CNY 汇率自动折算**，填进可修改的人民币参考原价输入框。汇率提供方按日更新，使用日期会显示在作品卡片里。活动实付价仍按人民币填写；折数会使用同币种数据计算。
- 同时通过 `?workno=RJ123456&endpoint=dlwatcher` 获取史低记录；优先展示史低日元成交价（若有）、估算人民币价和史低折扣（`90% OFF` 约为 `1折`）。历史人民币价按**本次查询使用的汇率**估算，不是历史成交当天的汇率。
- 汇率接口为每日更新的 [fawazahmed0 currency-api](https://github.com/fawazahmed0/exchange-api)，优先使用 jsDelivr CDN，失败时切换 Cloudflare Pages；缓存6小时。若两条线路都不可用，则使用已保存的旧汇率并标注，或提示失败，供用户手动填写。
- 在「设置」中可一次填写「同价活动统一实付价」，之后新增的作品会自动带入该价格（例如统一优惠价 7.1 元）；填写 0 则每部单独录入。
- 自动导入仅填补尚未填写的作品名、CV、时长。已填的个人判断、试听评分、购物车状态和实际人民币价格不会被覆盖。
- 查询失败或缺少字段时可以手动补充；历史价格与参考汇率均以来源及可用性为准。本地评分与购买记录不会随查询上传。

## 使用流程

1. **第一印象**：作品名、RJ、BK/标题/CV、现价和原价，记录初步兴趣。
2. **详情排雷**：时长、剧情设定、个人雷点、最期待的内容、音轨结构和 BK 特典。
3. **试听核查**：日常声线、亲密演绎、棒读情况、音效收音。
4. **量化打分**：七个喜好维度（权重总计 100%），四个可选购买时机维度。
5. **人工决定**：把作品放入候选、暂存或跳过；到购物车按照分数排序，结合名额/预算手动勾选本次购买。

## 评分方式

**喜好分（0–100）**：默认基准 50 分。每个维度选择 `-2/-1/0/+1/+2`，按照权重加减。

```
喜好分 = 50 + Σ (维度权重 × 档位 / 4)
```

- BK与标题 5%；CV吸引力 10%；剧情人设 20%；日常试听 25%；亲密试听 25%；音频制作 10%；内容结构 5%。
- 七项全部填写才计算正式喜好分。**未知**和**普通（0）**分开。
- 购买时机维度：实付价格 40%、折扣力度 30%、历史价 20%、版本与优惠 10%。只按已回答权重归一化，显示覆盖度。
- 有时机评分时，综合参考分 = 喜好分 × 85% + 时机分 × 15%；未填写时直接显示喜好分。
- 剧情绝对雷点、时长低于个人设定、棒读、日常/亲密试听不喜欢：一票否决，优先于分数。
- 购买价、折扣等为提示性规则；个人可调整偏好参数。
- 最终手动决定，计算结果仅供参考。

## 当前范围

- 无需账户；支持联网通过共享 Worker 查询 DLsite 商品基本资料。评分和记录保存在浏览器本地；不自动查询史低或已购作品。
- 支持多作品记录、持久保存、筛选流程、评分理由、购物车二筛、预算统计、JSON 导入与导出。
- 为购物决策原型，参数可根据真实听后体验继续校准。

## 隐私说明

评分、购买意愿和候选清单存储于本机浏览器，不会随 RJ 查询上传；点击自动获取时会将 RJ 号发送至 Cloudflare Worker，同时请求公开的汇率 API。导出备份请自行妥善保管。GitHub 仓库里只有代码，没有个人作品记录。
